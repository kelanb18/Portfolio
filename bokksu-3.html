Native Shopify sections

Replacing a page builder with sections the brand team could manage in Shopify.

SUGOI MART
EARLIER WORK

The work

Our third-party CMS was significantly hurting site speed. This project replaced it with a native Shopify section architecture — no external page builder, no performance overhead. The new system also unlocked capabilities the old CMS couldn't support: dynamic personalization via customer tags and UTM parameters, section-level scheduling, and new interactive features like a sticker/badge system for promotions and product callouts — all configurable in Theme Customizer without a dev ticket.

Shipped as part of a full brand refresh: redesigned homepage with multi-slide hero carousel, and two new brand pages (About Us, Why Choose Us) built from Figma. Each section is a self-contained Liquid component — brand team owns content fully, no dev needed for updates or scheduling.
