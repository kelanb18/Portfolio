EARLIER WORK

The work

Migrated four Shopify storefronts into a new Shopify Plus organization. Each store needed its apps and connections set up again: apps audited for multi-store vs single-store licensing, Shopify Flow automations rebuilt from scratch, API connections re-established, metafields reconfigured, and themes tested.

Used Matrixify for data migration and planned phased DNS cutovers to minimize downtime risk. Coordinated across the dev team and external vendors throughout.

Ran as program manager: scoping, sequencing, vendor coordination, QA sign-off, and post-migration monitoring. Engaged Shopify Professional Services as a coordination partner.
